## 1. Разработка программы Калькулятор с следующими возможностями:
 
  * Графический интерфейс
  * Защита от неправильного ввода, которая работает постоянно (если пользователь вводит не корректные данные, программа просит ввести правильные). Программа не вылетает
  * Несколько режимов работы, между которыми пользователь может переключаться:
    - Калькулятор с стандартными арифметическими операциями (+-/*)
    - Решатель линейных и квадратных уравнений
    - Модуль для отрисовки введенной пользователем зависимости y(x) с выбором границ отрисовки по осям абсцисс и ординат
  * Пользователь может свободно переключаться между режимами работы Калькулятора до и полсле использования каждого их них
