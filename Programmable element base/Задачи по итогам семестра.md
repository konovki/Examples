## 1. Разработка программы Калькулятор с следующими возможностями:
 
  * Графический интерфейс
  * Защита от неправильного ввода, которая работает постоянно (если пользователь вводит не корректные данные, программа просит ввести правильные). Программа не вылетает
  * Несколько режимов работы, между которыми пользователь может переключаться:
    - Калькулятор с стандартными арифметическими операциями (+-/*)
    - Решатель линейных и квадратных уравнений
    - Модуль для отрисовки введенной пользователем зависимости y(x) с выбором границ отрисовки по осям абсцисс и ординат
  * Пользователь может свободно переключаться между режимами работы Калькулятора до и полсле использования каждого их них

## 2. Разработка Telegram-бота с следующими возможностями:
 * Добавлены базовые команды через BotFather, например: start, help, quest 
 * Бот может отвечать на некоторые сообщения и команды пользователя
 * Добавлена возможность игры в Квест с не менее чем 7-ю локациями. Локации НЕ должны быть расположены по сюжету линейно одна за одной, напрмер игрок идет по одной доступной дороге, затем заходит в одну доступную дверь и т.д.
 * При прохождении квеста пользователь использует кнопки в чате и кнопки меню, 
 * Приветствуется добавление в Квест случайных элементов
 * Не забудьте, что для прохождения квеста одновременно несколькими игроками, боту необходимо хранить инфоормацию о каждом пользователе.

# Форма сдачи
Каждая команда загружает разработанные программы в репозиторий на GitHub. У репозитория параметр видимость должен быть установлен в значение Public. Участки программного кода должны быть дополнены комментариями. Над одним проектом работает не более двух человек. При подозрении взаимного плагиата будут заданы уточняющие вопросы.
